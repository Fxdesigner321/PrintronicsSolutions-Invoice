# Printronics Solutions — Dynamic Service Invoice

## Included
- `index.html` — two-step invoice application
- `style.css` — invoice + responsive UI styling
- `script.js` — dynamic rows, calculations, preview, print and PNG download

## How it works
1. Open `index.html` in a browser.
2. Page 1 is the data-entry screen.
3. Add/edit service rows, quantity and amount.
4. Choose Discount / Adjustment as either PKR amount or percentage.
5. Click **Generate Invoice**.
6. Page 2 shows the invoice in the supplied Printronics Solutions visual style.
7. Use **Print** or **Download Image**.

Bootstrap 5.3 and html2canvas are loaded from CDN, so an internet connection is needed for those libraries.
